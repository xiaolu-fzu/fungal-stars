# 真菌星域 Fungal Realm (V0)

一款受 **Eufloria** 启发的网页即时战略/RTS 小游戏,纯 **Canvas 2D** 编写,零引擎、零依赖。

## 玩法
- 点击我方星球选中,再点击目标星球派兵(可累计数量,右键向目标派遣)。
- 造**繁殖树**生产袍子、造**防御树**守卫、种**花**产兵。
- 袍子继承出生星球的**能量/力量/速度**,在**轨道带内主动追击**敌人与敌方繁殖树,用**阵营色激光**点射。
- 中立星球:派兵 + 种繁殖树即可占领(无需攻核心)。
- 敌方星球:清空守军 → 摧毁繁殖树 → 攻入核心耗尽血量 → 占领。

## 运行
直接用浏览器打开 `index.html`,或用本地服务:

```bash
python -m http.server 8128
```
浏览器访问 `http://127.0.0.1:8128/`

> 开局自带一段新手教程:锁定 7 倍镜头,带你种植繁殖树、对抗第一波敌军,随后解锁自由游玩。

## 目录

- `game.js` 主逻辑(相机 / 战斗 / 教程 / 渲染)
